One real ML model, honestly measured

A judge who hears "precision and recall 1.0" should ask whether that was measured on scenarios the team wrote itself — ours was. So alongside the rules there is one trained model, scored a different way.

An unsupervised behaviour model

Scikit-learn Isolation Forest, scored 0–100: how unlike the bank's other accounts an account behaves (age, in/out counts, how fast money passes through, fan-out, devices shared). No labels anywhere — it has never been told which accounts are mules.

A separate signal, not a 16th rule: it never changes a warning sign, priority or decision.

A genuine hold-out

Fresh synthetic banks at random seeds, built through the demo-data generator — a different code path from the hand-written scenarios, never scored again. Measured without labels touching the fit.

On the case: the model shows up to 3 plain-language reasons per account — its value against the bank's typical value — on the Warning signs tab. On the AI & system health page: the model card, and a "Run hold-out evaluation" button a supervisor can press on demand.

Honest about limits: well above chance, far from the scenario-only 1.0. Labelled everywhere as a synthetic hold-out, not real-world performance.
