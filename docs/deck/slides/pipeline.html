CODE

GEMINI FLASH

CODE

PERSON

Gemini never calculates: money, balances, rules and validation are deterministic code. The agent cannot run free-form queries; tool targets must already exist in the snapshot. If Gemini is down, every AI step shows “Not analysed” and a facts-only report is built by code.
